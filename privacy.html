Privacy Policy

Effective date: 2026-11-19. This policy describes the only Google user data Surge Shorts Uploader accesses, and what it does with that data.

Who operates this app

Surge Shorts Uploader is a personal automation tool operated by its developer, Taegyun Kim (Google Cloud project surge-shorts). It creates short market-news videos, uploads them privately to the developer’s own YouTube channel, and records production logs in the developer’s own Google Sheet and Drive files.

It is not a public service. There is no sign-up, and it does not collect data from any other person. The only Google account it is authorized to use is the developer’s own account.

This website is a static disclosure page. It does not use cookies, analytics, or tracking scripts, and it does not collect visitor information.

Google API scopes

The app requests only these OAuth scopes:

  • https://www.googleapis.com/auth/youtube.upload (youtube.upload) — upload videos to the developer’s own YouTube channel and set them private.
  • https://www.googleapis.com/auth/youtube.force-ssl (youtube.force-ssl) — add captions and thumbnails to those videos on the developer’s own channel. This scope can also manage other YouTube account data, such as videos and captions. The app uses it only for the developer’s own uploads, captions, and thumbnails.
  • https://www.googleapis.com/auth/drive.file (drive.file) — create and edit only the Google Drive and Google Sheets files that this app itself created. It cannot open the rest of the developer’s Drive.

Data accessed and why

  • Video files, captions, thumbnails, and the related title, description, and privacy status needed to publish a private video on the developer’s own channel.
  • Production-log rows written to Sheet and Drive files that this app created in the developer’s own Drive.
  • OAuth access and refresh tokens for the developer’s own Google account, so the app can keep performing those uploads and log writes.

The data is used only to perform these uploads and logging for the developer’s own accounts. It is not used for any other purpose.

Storage, sharing, and advertising

OAuth tokens are stored on the developer’s private server. Uploaded videos remain in the developer’s own YouTube channel. Log files remain in the developer’s own Google Drive. Nothing from those accounts is placed on this public website.

Google user data is not sold, is not shared with third parties, and is not used for advertising. The app does not transfer data to advertising platforms, data brokers, or information resellers, and it does not use the data to determine credit-worthiness or for lending.

Google API Services User Data Policy

Surge Shorts Uploader’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Limited Use, applied to this app, means:

  • Google user data is used only to provide the features described on this site: privately uploading the developer’s own videos, captions, and thumbnails, and writing production logs to files this app created.
  • Transfers of that data are not allowed, except to provide those features with the user’s consent, for security (for example, investigating abuse), to comply with applicable law, or as part of a merger, acquisition, or sale of assets after the user’s explicit prior consent. This app does not make those transfers. It runs only for the developer.
  • Humans do not read the data unless the user has affirmatively agreed to view a specific item, it is necessary for security, it is necessary to comply with applicable law, or the data (including derivations) is aggregated and used for internal operations in line with applicable privacy law. The developer is the account holder and operates the tool on their own account.
  • All other transfers, uses, or sales of user data are prohibited, including selling or transferring it to advertising platforms, data brokers, or information resellers; using it to serve ads, including retargeting, personalized, or interest-based advertising; and using it to determine credit-worthiness or for lending.

These limits apply to raw Google user data and to data aggregated, anonymized, or derived from it.

Revoking access

You can remove Surge Shorts Uploader’s access at any time from Google Account permissions (https://myaccount.google.com/permissions). After access is removed, the app can no longer call YouTube or Drive for that account.

Deletion requests

To ask for deletion of data this app stores, email mellll2772@gmail.com. The developer will delete the stored OAuth tokens and the log files this app created. Videos already uploaded can also be removed from the developer’s YouTube channel. This site itself stores no Google user data to delete.
